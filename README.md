# 日常工作

用于管理每日任务、记录工作进展和沉淀经验，方便回顾与持续改进。

## 使用方式

1. 每天开始工作前，确定当天最重要的三件事。
2. 工作过程中更新任务状态，记录结果、问题和待办事项。
3. 下班前完成简短复盘，安排下一步行动。
4. 每周整理工作成果和未完成事项。

## 每日工作模板

复制以下模板，按日期填写。记录较多时，可放入 `daily/YYYY-MM-DD.md` 文件。

```markdown
# 工作记录：YYYY-MM-DD

## 今日重点

- [ ] 重点任务一
- [ ] 重点任务二
- [ ] 重点任务三

## 工作记录

| 事项 | 状态 | 结果或相关链接 |
| --- | --- | --- |
| 示例任务 | 待开始 / 进行中 / 已完成 / 阻塞 | |

## 问题与协作

- 遇到的问题：
- 需要的支持：
- 下一步行动及负责人：

## 今日复盘

- 完成的成果：
- 学到的经验：
- 可以改进的地方：

## 明日计划

- [ ] 待办事项一
- [ ] 待办事项二
```

## 每周回顾

- 本周完成了哪些重要成果？
- 哪些事项延期了，原因是什么？
- 有哪些值得保留的方法和经验？
- 下周最重要的目标是什么？

## 记录约定

- 任务描述尽量具体，写清预期结果和截止时间。
- 完成任务时补充成果或相关链接，方便后续查阅。
- 将较大的任务拆分为可执行的小步骤。
- 提交前检查内容，避免上传密码、密钥或敏感业务信息。
